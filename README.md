# Minesweeper

`Minesweeper` — это проект игры «Сапёр» на C# с графическим интерфейсом Windows Forms и отдельным ядром игровой логики.

## Что внутри репозитория

- `Core` — библиотека с основной логикой игры:
  - генерация минного поля;
  - проверка выбранной клетки;
  - подсчёт мин вокруг клетки;
  - рекурсивное открытие пустой области.
- `WinFormsApp` — desktop-приложение (GUI) с игровым полем, выбором сложности, таймером, флагами и аудио/визуальными эффектами.
- `Test` — консольный проект для ручной проверки логики `Core` на большом поле.

## Технологии

- **C# / .NET 8** (`net8.0`, `net8.0-windows`)
- **Windows Forms** для интерфейса

## Как работает

1. При старте новой игры создаётся объект `Minesweeper` с параметрами поля (высота, ширина, число мин).
2. До первого хода поле не минируется.
3. На первом открытии клетки вызывается генерация мин, при этом стартовая клетка гарантированно не содержит мину.
4. При открытии клетки:
   - если там мина — игра заканчивается поражением;
   - если рядом есть мины — показывается число;
   - если рядом мин нет — автоматически открывается область пустых клеток и их соседей.
5. Победа наступает, когда открыты все не-минные клетки.
